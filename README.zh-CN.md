# JungleHelper

适用于 Shared 运行时的 JungleHelper 移植。工作区位置：`Mods/JungleHelper/`。

项目：

- `Celeste.Mods.JungleHelper.csproj`

依赖仓库：**Shared, MaxHelpingHand**。先按 [Tools README][tools-readme-zh-cn]
准备 Shared 资源，再构建主项目：

```powershell
dotnet build ./Mods/JungleHelper/Celeste.Mods.JungleHelper.csproj -c Release
```
