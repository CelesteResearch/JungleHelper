# JungleHelper

JungleHelper port for the Shared runtime. Workspace location: `Mods/JungleHelper/`.

Projects:

- `Celeste.Mods.JungleHelper.csproj`

Repository dependencies: **Shared, MaxHelpingHand**. Prepare Shared resources using the [Tools README][tools-readme], then build the main project:

```powershell
dotnet build ./Mods/JungleHelper/Celeste.Mods.JungleHelper.csproj -c Release
```
